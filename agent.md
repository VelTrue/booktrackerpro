Правила проекта для Book Tracker

## Стек технологий
 - язык: TypeScript 
 - Фреймворк: React
 - Стилизация: Tailwind CSS
 - Стейт-менеджминт: Zustand 
 - Даты: date-fns
 - Иконки: lucide-react

## Правила именования
- Компоненты: PascalCase (например, `BookCard.tsx`, `BookList.tsx`)
- Утилиты/хуки: camelCase (например, `useBooks.ts`, `formatDate.ts`)
- Типы/интерфейсы: PascalCase с суффиксом (например, `IBook`, `BookProps`)

## Стиль кода
-  Запрещено использовать `any` — всегда указывай конкретные типы
-  Все компоненты — функциональные, со стрелочной функцией
-  Явные типы возврата для функций (например, `: React.FC`, `: void`, `: string`)
-  Импорты группировать: React → библиотеки → компоненты → утилиты

## Управление состоянием
- Глобальное состояние: Zustand (хранилище в `store/`)
- Локальное состояние: `useState` внутри компонентов
- Данные в localStorage: ключи с префиксом `bookTracker_` (например, `bookTracker_books`)

## Запреты для агента
-  Не удаляй существующую функциональность без явной просьбы
-  Не рефакторь код, не относящийся к задаче
-  Не меняй целые файлы — только точечные правки (diff)
-  Всегда показывай, какие именно строки меняешь
-  Не используй смайлики/эможди

## Используемые библиотеки
- `date-fns` — форматирование дат
- `lucide-react` — иконки
- `zustand` — управление состоянием (если используешь)
- `react-router-dom` — если есть навигация
